01Define tracked and material+

A tracker begins with an explicit promise: named jurisdictions, authority types, topics, event types, collection cadence, known exclusions, and a review date. “Tracked” means only that the stated collection and review steps ran; it does not mean every legal development was found.

03Bound the watch list+

  2. Create topics without keyword tunnel vision

    40 minutes

    Keywords are discovery aids, not coverage proof. Combine controlled topics, agencies, committees, sponsors, cited statutes or CFR parts, entities, products, stages, and exclusion rules; preserve unmatched items for sampling so the taxonomy can reveal blind spots.

04Collect without claiming completeness+

Prefer documented APIs, bulk data, feeds, or official notifications, but verify what each interface omits and how it represents updates. Capture pagination, windows, time zones, identifiers, corrections, withdrawals, and endpoint changes; never infer legal status from HTTP success.

  2. Preserve collection receipts and failures

    40 minutes

    Each run needs a start and end time, request boundary, pages or cursors, item count, warnings, retry state, and source timestamp. A failed or partial run must create a visible coverage gap rather than silently reuse stale results.

05Detect and classify change+

Store retrieved versions rather than only the latest text. Normalize presentation cautiously, calculate a digest, retain the original artifact, and compare structurally meaningful units. Cosmetic differences, corrected metadata, substituted text, and legal amendments require different labels.

Relevance and urgency are organizational judgments. Use separate, inspectable factors such as subject match, affected entity, stage, deadline, geographic scope, operational dependency, reversibility, and evidence confidence. Unknown data must not receive a reassuring default score.

Use it responsibly

What supports this—and where it stops.

Keep the practical material attached to its evidence, method, assumptions, and limits.

Evidence

  • Dated coverage and exclusion contract
  • Official-source register and canonical versioned records
  • Collection receipts, change comparisons, citations, evaluation cases, and reviewed release decision

Method

  1. Define coverage and authority
  2. Collect from primary sources
  3. Normalize and compare versions
  4. Separate detection from interpretation
  5. Publish reviewed, traceable alerts

Assumptions

  • Learners select a bounded decision, jurisdiction set, and official sources
  • Authorized jurisdiction and domain reviewers determine materiality, legal status, and permitted distribution

Limitations

  • The public course does not connect sources, run continuous monitoring, send alerts, or guarantee detection
  • Exercises and summaries are informational and do not replace jurisdiction-specific legal advice

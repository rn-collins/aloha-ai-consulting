What this practice is

A systems practice for questions too consequential or too complicated for a generic template.

The interface may be a website, dashboard, agent, assessment, portal, curriculum, report, or monitor. The actual work is defining what the system should know, which sources it should trust, how decisions should be made, where humans remain responsible, and how the system stays current.

For

How the work operates

The method is visible before the model is trusted.

Inputs

Primary sources, institutional materials, stakeholder interviews, existing workflows, policies, data, examples, and failure cases.

Processing

Source ranking, taxonomy, extraction, validation, logic mapping, workflow design, prototype testing, and evaluation.

Outputs

Decision-ready research, structured data, operating rules, interfaces, workflows, reports, training, and implementation packages.

Human review

Consequential claims, exceptions, approvals, escalations, professional judgment, and external delivery remain reviewable and assigned.

Limitations

No system eliminates uncertainty, replaces accountable professionals, or remains trustworthy without maintenance.

Assumptions

The client provides access to relevant materials, an accountable owner, timely decisions, and qualified review where required.

Framework

Define → Examine → Decide → Build. Define the actual decision; examine the work and responsibility; select a legitimate finding; build only the smallest responsible next move.

Four findings

Run a bounded AI experiment; redesign the process first; keep the work substantially human-led; or investigate further before deciding.

Key vocabulary

Human review: accountable examination with authority to change the outcome. Success measure: evidence that the intervention helps. Stop rule: a condition set in advance that pauses or ends use.

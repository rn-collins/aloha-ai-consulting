# Promise–Delivery Reconciliation Program

## Mandate

Reconcile the entire defined Aloha AI production estate with what a reasonable visitor is led to expect. The program does not treat authored copy, a resolving link, a passing build, or a deployed page as proof that a promise is delivered.

Every in-scope surface is inventoried. Every explicit or interface-implied promise receives a permanent ID, evidence locations, a present-reality classification, a disposition, acceptance criteria, and a terminal release record. New public promises must enter the ledger before release.

## Non-negotiable controls

1. Never silently narrow the production estate.
2. Keep discovery separate from implementation.
3. Count coverage with denominators.
4. Preserve every occurrence of a repeated promise.
5. Distinguish structural resolution from substantive fulfillment.
6. Do not substitute copy correction for requested product delivery.
7. Do not remove a difficult promise merely to improve completion statistics.
8. A deferred promise is terminal only when its public status is accurate and its dependency is recorded.
9. A delivered promise is terminal only after acceptance criteria and production verification.
10. Repeat a clean-room inventory before declaring the program complete.

## Evidence states

`inventoried` → `classified` → `planned` → `building` → `locally_validated` → `pr_open` → `gates_passed` → `merged` → `deployed` → `production_verified` → `independently_reaudited`

No later state may be inferred from an earlier one.

## Baseline rule

The frozen baseline records what production commit `deb1073d` publicly contained on 2026-07-29 in Pacific/Honolulu. Broader buildout starts only after the route, resource, interaction, and promise totals reconcile and the snapshot passes `npm run promise:check`.

## Completion rule

The program is complete only when:

- every in-scope route is present in the frozen route inventory;
- every canonical resource and every public interactive occurrence is represented;
- every promise record has a disposition and observable acceptance criteria;
- no record remains unknown or merely discovered;
- every delivered record has release and live-production evidence;
- every deferred record uses accurate public language and names its dependency;
- all promise-governance tests pass; and
- a final independent sweep creates zero unrecorded promise records.

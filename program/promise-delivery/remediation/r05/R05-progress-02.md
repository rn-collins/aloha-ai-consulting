# R05 Progress Report 02 — Regulated Claims Checker Open Course

**Frozen audit baseline:** 325/325 evidence units; 4,289 grouped claims / 9,552 occurrences  
**Tranche:** R05 — Learning, assessment, and course runtime  
**Decision:** locally validated; R05 remains open

## 1. Purpose

This unit converts the Regulated Claims Checker from a curriculum preview into a complete set of public open materials. It does not activate enrollment, submissions, instructor review, account-synced progress, grading, a tutor, credential issuance, regulatory approval, production integration, or commercial capacity.

## 2. Canonical curriculum delivered

- One course record.
- Nine ordered modules.
- Eighteen substantive lesson records and generated lesson routes.
- Six assessment contracts, including an executable five-question knowledge check.
- Five verified official sources from FTC, FDA, and NIST.
- One bounded capstone with eight required evidence classes.
- Two weighted rubrics.
- One explicit planned-credential boundary record.
- Eight mapped learning outcomes.

The course teaches a bounded claims-review method: scope the product, audience, channel, and jurisdiction; extract express and plausible implied claims; build a dated authority register; map claims to governing questions and evidence; issue inspectable provisional dispositions; route consequential uncertainty to named people; evaluate false assurance and review burden; and package a release decision with unresolved blockers.

## 3. Learner runtime

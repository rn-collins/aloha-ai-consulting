# Meeting Capture Permission and Record Map

Version: MCPRM-1.0
Use: masterclass, clinic, and governed internal analysis
Not legal advice or recording authorization

## Deterministic disposition

Select exactly one: **Do not capture**, **Human notes only**, **Redesign and synthetic test**, or **Bounded pilot for separate approval**. The last still requires separate authority and does not authorize recording people.

## A. Decision identity

| Field | Required entry |
|---|---|
| Decision ID and version | Stable identifier |
| Owner and accountable executive | Named roles |
| Meeting class | One class, not “all meetings” |
| Purpose | Concrete downstream task |
| Decision / review date | Dates and triggers |
| Product/configuration | Exact version/settings or none |

## B. Meeting boundary and segments

Record each agenda segment’s purpose, participant roles and physical locations, attendance voluntariness, sensitivity, capture mode, bot entry/exit, non-capture alternative, and authoritative record. Fail closed if a late joiner, location change, protected transition, breakout, side conversation, accommodation disclosure, or objection cannot pause or remove capture reliably.

## C. People, power, and meaningful choice

Identify required attendance; control over employment, grades, benefits, contracts, funding, care, or status; private and public objection routes; consequence-free equivalent alternatives; language, disability, bandwidth, device, time-zone, and cultural needs; and immediate stop authority. Statutory recording consent does not prove organizational permission or meaningful choice.

## D. Authority packet

Record source IDs, pinpoints, reviewer, limitation, and disposition for interception/recording; workplace/labor; privilege/confidentiality; records/discovery; privacy/sector; accessibility/language; and cross-border/localization. Any unresolved applicable layer prevents a human pilot.

## E. Five-record separation

| Record | Purpose | Owner | Access | Retention | Correction | Authority |
|---|---|---|---|---|---|---|
| Raw audio/video | | | | | | Never assumed |
| Transcript | | | | | | Representational |
| Generated summary | | | | | | Probabilistic |
| Extracted actions | | | | | | Proposed until approved |
| Human-approved decision record | | | | | | State exact authority |

No artifact inherits another artifact’s access, retention, deletion, or status automatically.

## F. Vendor and data flow

Document collection trigger, processing, provider/model, training/reuse, human review, subprocessors, storage/support locations, telemetry, derived data, exports, integrations, admin defaults, deletion propagation, backup expiry, legal hold, security, version/change notice, and exit/portability. Unknown is blocking for a material flow.

## G. Accuracy and human review

Synthetic tests cover omitted or invented decisions, conditions, dissent, uncertainty, risk and deadlines; wrong speaker/action owner; interruption and late join; accents/languages and accommodation; poor audio, crosstalk, names, numbers, jargon and negation; protected-segment pause/removal; and divergence among transcript, summary, action, and decision record. Predefine scorers, thresholds, disagreements, stop rules, and incidents.

## H. Notice and control

Notice identifies entry, capture, purposes, artifacts, owner, access, retention, vendor flow, objection, equivalent alternative, correction, and incident contact in usable formats. A bot name, tile, beep, calendar clause, or continued attendance is not by itself recorded as sufficient consent.

## I. Stop rules

Stop or revert when capture escapes class/segment; authority becomes unresolved; choice is not meaningful; sensitive content reaches an unauthorized party; correction/deletion/pause/removal fails; summary/action errors cross threshold; configuration or flow changes; probabilistic output becomes personnel evidence; purpose expires; or incident/record ownership is absent.

## J. Final record

Record disposition, reasons, unresolved facts, prohibited uses, redesign, test scope, reviewers, affected-person input, approval still needed, evidence expiry, monitoring and incident owners, and next action. Completion does not mean legal clearance or permission to record.

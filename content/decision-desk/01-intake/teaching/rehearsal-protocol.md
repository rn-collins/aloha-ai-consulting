# Decision Desk 01 — complete rehearsal protocol

Version 1.0 · release gate · no rehearsal claimed until this record is completed

## Purpose

Rehearse the entire participant experience—not only the spoken lesson—from confirmation through follow-up. A rehearsal passes only when material, access, privacy, timing, facilitation, support, and decision-boundary defects have documented dispositions.

## Roles

- Facilitator
- Producer/timekeeper
- Accessibility observer
- Participant using keyboard-only navigation
- Participant using a current screen reader
- Participant using zoom/reflow
- Content/evidence observer
- Support responder
- Note owner with authority to stop the rehearsal

One person may hold multiple roles only if doing so does not invalidate the observation.

## Preconditions

- Release candidate and version IDs frozen.
- Fictional-data check passed.
- Article, Source Desk, slides, workbook, case, blank card, example, answer key, and follow-up guide reconciled.
- Delivery platform, captions, alternative formats, fallback link/dial-in, and private support path configured.
- Test confirmation/reminder/follow-up messages ready but not sent to real participants.
- Recording disabled unless separately approved and disclosed.
- Stop authority named.

## Test sequence

### A. Before-session journey

1. Review the public promise, price/date/timezone placeholders, boundaries, privacy, cancellation, and access path.
2. Run a test registration/payment path only when separately authorized; otherwise verify it remains inactive and label the gate open.
3. Deliver test confirmation and reminders to controlled test addresses.
4. Open every link on desktop and mobile.
5. Request an alternative format and verify private acknowledgment/routing.
6. Confirm no message implies certification, CLE, legal advice, product endorsement, recurring subscription, or active advisory acceptance.

### B. Ninety-minute content run

Run the full clock without skipping. Record actual start/end for every segment, instructions misunderstood, questions that require evidence changes, sensitive-disclosure interventions, inaccessible interactions, and content omitted under time pressure.

Observers verify:

- initial and final decisions can be recorded privately;
- source and synopsis can be compared without color or vision;
- answer key remains sealed until debrief;
- participants can work individually and in writing;
- facilitator distinguishes authority, vendor claim, observation, analysis, and unknown;
- the only supported current case disposition remains `human_led_only`;
- no statement authorizes product nomination, testing, live data, or pilot;
- timekeeping does not penalize an access need.

### C. Failure injections

Test at least:

- slides unavailable;
- captions unavailable;
- breakout rooms unavailable;
- participant cannot use a PDF;
- participant starts disclosing sensitive facts;
- broken material link;
- facilitator loses ten minutes;
- support contact receives an access request;
- a participant challenges a material claim;
- post-session correction changes a displayed fact.

Use the recorded fallback. If no fallback works, fail the relevant gate.

### D. Follow-up journey

Send the test post-session message, verify canonical versions and correction channel, submit one mock feedback item and one mock critical correction, observe acknowledgment/routing, and verify sensitive content is not copied into a public record.

## Acceptance criteria

- Full run lasts 85–95 minutes without removing source review, scoring, final disposition, or access alternatives.
- All essential content remains available when slides fail.
- Captions/transcript and untimed written path work.
- Keyboard, screen-reader, and zoom/reflow observations are recorded.
- Zero real sensitive data used.
- Zero unapproved affiliation, accreditation, outcome, product, or authorization claims.
- All critical/high defects are corrected and regression-tested.
- Medium/low defects have owners and dates.
- Confirmation, reminder, support, and follow-up copy remain inactive until operational approval.
- Rehearsal owner recommends pass, conditional pass, or fail with reasons.
- RN reviews the final record; release still requires explicit RN approval.

# Setup checklist

- [ ] Assign accountable owner and human reviewers.
- [ ] Copy the empty starter; preserve stable IDs and version control.
- [ ] Approve data classification, privacy, retention, and access rules.
- [ ] Populate and verify source records before claims.
- [ ] Validate schemas and resolve every failure.
- [ ] Configure voice and audience records.
- [ ] Run the worked example and reconcile every sentence.
- [ ] Confirm rights, accessibility, professional boundaries, and approvals.
- [ ] Record source-review cutoff and maintenance state.
- [ ] Archive the exact records used for every released output.

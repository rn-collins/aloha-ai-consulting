01Cookieless performance measurement, no ad tracking, no profile of you+

The site loads Vercel Speed Insights to measure anonymous load-performance data so Aloha AI can see whether pages are fast. It sets no cookies, does not follow you across other sites, and does not build an advertising profile. No advertising or third-party ad trackers run on the site.

02The tools run in your browser+

Public interactive tools, monitors, and figures compute on your device by default. Information entered into those browser-local tools is not transmitted to Aloha AI or a third party. If a page offers an optional connection to an external service, it identifies that connection and what you deliberately submit before you use it.

03Local conversion context and scoping records+

The contact page keeps only source route, offer ID, and inquiry type in session storage for no more than thirty minutes so the page can preserve where a visitor started. It does not store the answers entered into the scoping form. The attribution record can be cleared on the contact page and disappears when the browser session ends.

A scoping record is created in memory only. It leaves the page only if the visitor deliberately copies it, downloads it, or pastes selected text into a third-party booking form. Aloha AI does not receive the record through the public site.

04What is collected+

No account is required to use the public site. Public account creation and sign-in are disabled. Aloha AI does not currently operate a brand-owned public intake endpoint or email channel. Unlinked platform API foundations are deployed for development, but authenticated routes require a valid session, model delivery is disabled, and the public authentication endpoints fail closed unless an explicit production enablement flag is set.

  • If you book a call: the details entered in Microsoft Bookings, typically name, email address, and any note, are handled through the Northeastern-associated Microsoft account shown before you leave the site.
  • The browser-local scoping record is not submitted to Aloha AI.
05How it is used+

Information you send is used to respond to you and, if an engagement begins, to run that engagement. It is not added to a marketing list or used to contact you about something you did not request.

06Storage and third parties+

Bookings are processed by Microsoft Outlook Bookings under Microsoft’s terms and privacy practices. The current booking destination is associated with a Northeastern account. Aloha AI does not operate a public email or server-side intake path at this time.

07No sale of data+

Aloha AI does not sell, rent, or trade personal information.

08Your rights+

The site-held source context can be cleared directly on the contact page. To request access, correction, or deletion for information deliberately sent through Microsoft Bookings, open the current booking link, choose any available time, and put “privacy request — no meeting needed” in the note. Do not add sensitive information. RN will treat the booking as a request rather than a meeting and respond through the address you provide. A brand-owned request channel will replace this interim path before Aloha AI activates server-side intake.

09Children+

The site is intended for professionals and is not directed to children under 13. Aloha AI does not knowingly collect information from children. If you believe a child has sent information through Microsoft Bookings, use the current booking link and put “privacy request” in the note; do not include additional personal information.

10Changes+

If this policy changes, the effective date will change with it. Material changes are unlikely under the collect-almost-nothing approach.

11Privacy or security incidents+

If you believe information was exposed or the site behaved differently from this policy, use the current Microsoft Bookings link and put “privacy incident — no meeting needed” in the note. Include only the affected route, approximate date and time, and a safe way to reply; do not paste credentials, confidential material, or the exposed information itself. RN will preserve the report, investigate the affected path, suspend it when warranted, and document the disposition.

12Governing law+

This policy is governed by the laws of the State of Hawaii.

Accountability record

Evidence, method, assumptions, and limits.

The public record includes the conditions that limit how it should be read.

Evidence

  • The site’s configured analytics and interactive-tool behavior
  • The Microsoft Outlook Bookings path and browser-local scoping workflow
  • Documented absence of advertising trackers, public-site accounts, and server-submitted tool inputs

Method

  1. Minimize collection by default
  2. Keep public interactive processing in the browser
  3. Use cookieless aggregate performance measurement only
  4. Limit retained personal information to voluntary contact and engagement records
  5. Route access, correction, deletion, and incident reports through the disclosed interim request path

Assumptions

  • Deployed analytics and tool behavior remain consistent with this published policy
  • Third-party providers process information under their applicable terms and privacy practices

Limitations

  • This policy describes Aloha AI’s public site and direct contact paths, not every independently governed client system or third-party website
  • Applicable privacy rights may vary by jurisdiction and engagement
